## On-Page SEO

### Keyword research (what each page targets)

Keywords were chosen by thinking like a customer ("what would someone type to find this?") and checking
Google's own autocomplete / "People also ask" suggestions. No paid volume data was used. To check real
demand, use [Google Keyword Planner](https://ads.google.com/home/tools/keyword-planner/),
[Google Trends](https://trends.google.com/) and Search Console once the site is live.

Every page has its own meta description (about 130-145 characters), a canonical link, and Open Graph / Twitter tags.

### Structure, images, URLs, links, mobile

- **Headings:** one `h1` per page, then `h2` sections and `h3` sub-items, with no skipped levels (footer headings are `h2`).
- **Images:** descriptive hyphenated file names (e.g. `barista-whisking-matcha.jpg`) and alt text that describes the photo.
- **URLs:** short, lowercase, descriptive (`menu.html`, `about.html`, `contact.html`). `services.html` was renamed to `menu.html`.
- **Internal links:** descriptive anchor text between related pages (e.g. "matcha and coffee menu"). No orphan pages.
- **Mobile:** viewport meta tag, responsive layout, no sideways scrolling, text of at least 12px, tap targets of at least 44px (checked at 320-1280px wide).
- **Crawling:** `robots.txt` and `sitemap.xml`; `CafeOrCoffeeShop` structured data (JSON-LD) on the contact page.
